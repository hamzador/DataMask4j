Get started with local data masking

Java 21 and Maven 3.9+ are required. Build the unpublished snapshot locally:

git clone https://github.com/hamzador/DataMask4j.git
cd DataMask4j
mvn -B -ntp -pl datamask4j-cli -am clean verify
mkdir -m 700 masked

Classify every field

Example synthetic customers.csv:

email,notes,country
fixture@example.test,synthetic,FR

Example policy.yml:

fields:
  email:
    strategy: redact
  notes:
    strategy: drop
  country:
    strategy: keep

Run the CLI

java -jar datamask4j-cli/target/datamask4j-cli-0.1.0-SNAPSHOT-standalone.jar \
  mask --format csv --input customers.csv \
  --output masked/customers.csv --policy policy.yml

Expected result:

email,country
[REDACTED],FR

Use --format json for a flat JSON array of string/null objects. HMAC policies require --key-file, an owner-only file of exactly 32 raw random bytes. Never supply a key value in the command line or policy.

File safety

The CLI requires trusted local paths and a private POSIX directory (0700) with hard-link support. It writes a 0600 staging file and publishes after success without overwriting. A crash may leave a private temporary file. Windows-native support and crash durability are not provided.

Use the Java API

var policy = MaskingPolicy.builder()
    .field("email", FieldRule.redact())
    .field("notes", FieldRule.drop())
    .field("country", FieldRule.keep())
    .build();
var masker = new DataMasker(policy);

See the Java examples and security limitations.
