# Security policy

DataMask4j is in early development; no production-supported release exists. Please report vulnerabilities privately via GitHub's private vulnerability reporting mechanism if enabled, or request a private contact channel through an issue without describing the vulnerability. Never attach personal data, secret keys, credentials or production dumps. Use synthetic reproductions.

The project provides masking and scoped pseudonymisation, not a guarantee of anonymity, regulatory compliance or production readiness. Do not process real sensitive datasets until your organisation has reviewed the threat model, controls and applicable legal requirements.

See [threat model](docs/threat-model.md).
